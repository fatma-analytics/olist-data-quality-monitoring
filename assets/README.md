# PNG du dashboard

Les PNG de ce dossier sont des visualisations dérivées des agrégats produits à partir du **Brazilian E-Commerce Public Dataset by Olist**.

Source et attribution : Olist, *Brazilian E-Commerce Public Dataset by Olist*, [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), licence [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/). Les graphiques sont publiés sous cette même licence en tant que dérivés des données. Les CSV bruts ne sont pas inclus.

Après une nouvelle exécution du pipeline, régénérez les images avec :

```bash
python scripts/render_dashboard_assets.py
```
